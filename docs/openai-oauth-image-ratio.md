# OpenAI OAuth 生图比例

当前订阅 OAuth 生图链路已实测可以通过提示词引导画布比例。公开 Images API 的 `size`、`quality` 不代表在此链路上同样可靠；本项目不承诺订阅账号可精确控制像素、画质或原生 4K。

## 调用

向 `/v1/images/generations` 发送以下请求，鉴权仍使用本站 API Key：

```json
{
  "model": "gpt-image-2.5-sunburst",
  "prompt": "白色背景上的红色陶瓷杯",
  "aspect_ratio": "9:16"
}
```

`aspect_ratio` 是**本网关扩展参数**，不是已经验证存在的上游参数。OAuth 适配器将其转换成画布比例提示词，不设置隐含分辨率或画质，不裁剪、不缩放图片。JSON 和 multipart 请求均可使用；值为两个 1–10000 的正整数，以冒号分隔。等价比例会约分。空值或错误类型会作为请求参数错误返回。

目前实测的引导比例为 `9:16`、`16:9`、`1:1`。其他比例可以表达，但尚未逐一验证。返回像素可能因模型选择、生成结果和整数取整而变化；提示词引导不能保证严格比例，请检查返回原图的实际尺寸。请求比例与提示词冲突时，应先统一客户端输入。

未传 `aspect_ratio` 的旧请求保持原行为。`size` 和 `quality` 不会被覆盖，但在当前 OAuth 链路上的控制尚未验证可靠。若同时发送这些字段，不要把所请求的分辨率视为已获得的分辨率。

API Key 原生上游转发保持原样，不应用此提示词转换；其比例和尺寸能力取决于对应平台支持的参数。此扩展用于 Images 入口的 OAuth 请求，不会自动作用于客户端直接发送到 `/v1/responses` 的任意工具定义。

所有成功结果仍依据上游实际响应和解码后的图片尺寸报告、计费，不将比例引导伪装成精确像素支持。
